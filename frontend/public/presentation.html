// PROBLEM & SOLUTION

Overcoming Interview Friction

Bridging the critical gap between static text chatbots and high-stakes human interviews.

⚠️
Traditional Interview Bottlenecks
Recruitment Challenges
  • Severe Recruiter Fatigue: Senior engineers spend 40+ hours per month repeating initial screening conversations.
  • Subjectivity & Inconsistent Rubrics: Human interviewers vary drastically based on mood, energy, and unconscious bias.
  • Candidate Anxiety: Candidates lack realistic, low-stakes environments to practice articulating code and architecture out loud.
  • Text Chatbots Are Inadequate: Text-only LLMs do not simulate eye contact, speaking pace, or verbal pressure.
✨
Virtual Interview Pro Solution
Autonomous AI Spatial Pipeline
  • Lifelike 3D Spatial Presence: Real-time 3D avatars with eye contact tracking, blinking, nodding, and greeting waving.
  • Dynamic Resume Grounding: Ingests candidate resumes (PDF/DOCX) to synthesize 15 grounded, factual questions.
  • Granular 0-10 Rubric: Multi-vector grading across correctness, relevance, completeness, and clarity.
  • Dual-Mode Studio: Supports solo candidate practice and multi-candidate enterprise hiring campaigns with CSV telemetry.

// 3D RIGGING & KINEMATICS

📐 Procedural Lip-Sync & Biomechanical Kinematics

Trigonometric phonetic simulation, stochastic eye-blinking, and inverse arm kinematics.

👄
Procedural Viseme Algorithm
Mathematical phonetic driver
  • Syllable Modulator:
    S(t) = |sin(25t) · cos(20t)| · 0.8 + 0.2
  • Multi-Viseme Target Driver:
    • viseme_aa = max(0, sin(6.2t)) · S(t) (Open /a/)
    • viseme_ee = max(0, sin(6.2t + 2.0)) · S(t) · 0.8 (/i/ & /e/)
    • viseme_oo = max(0, sin(6.2t + 4.0)) · S(t) · 0.75 (Pursed /u/)
    • viseme_mbp = max(0, sin(9.5t + 1.2)) · 0.7 (Plosives M, B, P)
  • Simultaneous Bone Lerp: Modulates jaw bone rotation (alpha: 0.5) to provide depth on both bone-driven and morph-driven avatars.
👁️
Gaze, Blinking & Gestures
Natural non-verbal simulation
  • Stochastic Blinking: Countdown timer (2.5s to 6.0s). When timer < 120ms, eyelid bones rotate +0.35 rad and morphTarget 'blink' lerps with alpha 0.6.
  • Eye Contact & Saccades: 85% probability lock on camera center (0, 0); 15% subtle micro-saccades (±0.07 rad) to eliminate robotic staring.
  • Conversational Head Nod: Neck pitch lerps to talkTilt + sin(4.2t)·0.03 + gaze.y; spine breathing sways at sin(2.0t)·0.012 rad.
  • Greeting Kinematics: Smooth inverse-lerp waving animation between calibrated IDLE_POSE and WAVE_POSE with sine oscillation (sin(3.4t)·0.22).
// VOICE INTELLIGENCE

🗣️ Real-Time Voice Synthesis & Speech-to-Text

Heuristic multi-accent TTS matching and continuous Web Speech API transcription.

🔊
Text-to-Speech (TTS) Architecture
Persona-Driven Heuristic Matcher
  • 4-Tier Heuristic Matcher: (1) Language locale tag (en-IN, en-GB, en-US), (2) Keyword pool ('Guy', 'David', 'Samantha', 'Ravi', 'Google'), (3) Regex gender filters (/male/ vs /female/), (4) Fallback candidate pool.
  • Speech Lifecycle Hooks: Hooks into onstart, onend, and onerror to actuate 3D mouth lip-sync, waving gestures, and HUD live wave bars.
  • Universal OS Support: Seamless operation across Windows, macOS, ChromeOS, and Linux.
🎙️
Speech-to-Text (STT) Transcription
Continuous Real-Time Streaming
  • Continuous Audio Streaming: Web Speech API SpeechRecognition with interimResults=true shows live words on screen as the candidate speaks.
  • Non-Destructive Text Buffer: startingTextRef buffers existing text so candidates can combine speaking and manual typing seamlessly.
  • Proactive Permission Handling: Explicit navigator.mediaDevices.getUserMedia check with clear toasts if mic is blocked.

// AUTOMATED EVALUATION

📊 Multi-Vector AI Scoring & Candidate Feedback

Objective 0-10 evaluation rubric rewarding depth and clarity without penalizing conciseness.

1. Technical Correctness
0 - 10 Pts

Factual accuracy, algorithmic soundness, memory structures, and industry best practices.

2. Relevance & Focus
0 - 10 Pts

Directly addressing the problem without wandering, rambling, or providing irrelevant filler.

3. Completeness
0 - 10 Pts

Addressing edge cases, scalability bottlenecks, failure modes, and architectural trade-offs.

4. Clarity & Delivery
0 - 10 Pts

Crisp communication, structured explanations, and clear technical terminology.

📋 Comprehensive Post-Interview Candidate Report
• Cumulative Score: Total score out of 150 (e.g. 138/150) with overall benchmark percentage.
• Ideal Answer Comparison: Side-by-side view of candidate answer vs. gold-standard ideal response.
• Actionable Feedback: Constructive coaching and advice on technical improvements.
// SYSTEM ARCHITECTURE

🏗️ Full-Stack Technology Architecture

High-performance client rendering, robust REST backend, and multi-model AI routing.

💻
Frontend Architecture
React 18 + Vite + Three.js
  • Three.js & R3F: Hardware-accelerated 3D canvas rendering avatars, obsidian desks, laptops, and studio lighting.
  • MicroSlats WebGL Shader: Interactive fluid wave shader powered by OGL for dynamic cosmic backdrops.
  • Web Speech API: Native browser SpeechRecognition (STT) and SpeechSynthesis (TTS).
  • Cyber-Glass Design: CSS glassmorphism, responsive HUD overlays, and Lucide icons.
⚙️
Backend Architecture
Django REST Framework
  • REST API Endpoints: Question generation, interview submission, and telemetry dashboard.
  • Document Text Extraction: Multi-page PDF text extraction via pypdf and DOCX via python-docx.
  • Relational Data Model: HostedInterview and CandidateAttempt models with UUID tokens.
  • CSV Serialization: Instant dynamic CSV generation for ATS integration.
🧠
AI & Gateway Layer
OpenRouter Multi-LLM
  • 6-Tier Redundancy: GPT-4o-mini, Gemini 2.0 Flash, Claude 3.5 Haiku, Llama 3.3 70B, Mistral, Qwen.
  • Structured JSON Output: Enforces deterministic schema validation for questions and grading.
  • Few-Shot Prompt Engineering: Grounds evaluation strictly against factual technical criteria.
  • Fault-Tolerant Retries: Automatic backoff and timeout handling.
